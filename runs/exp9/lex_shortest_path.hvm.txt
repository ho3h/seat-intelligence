// t3_lex_shortest_path (GRAPH-SWING-2, runs/exp9). Keys (weight, hops) are packed into one number W*128 + H (fits
// 24 bits for n <= 128, w <= 1000), so the exp5 frontier Bellman-Ford from t with arc weights w*128+1 computes the
// lexicographic (weight, hops) distance D. The greedy successor nxt(u) = min{v ~ u : D(v) + w'(u,v) == D(u)} is
